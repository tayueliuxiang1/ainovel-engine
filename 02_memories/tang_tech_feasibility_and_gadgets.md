# 贞观工科实操阶梯与随身神器可行性记忆卡 (Tang Tech Feasibility & Gadgets)

## [记忆卡-11] 工科创客在唐三阶技术实操边界

### 1. 第一阶梯：开局独立手搓 / 庄园3至7天内立即可成
- 核心逻辑：纯靠现代力学构型与几何差，不需要前置工业链，使用既有木石、青铜、皮革即可完成。
- 提水龙骨车完全体：多级木质灯笼齿轮与锥形齿轮传动（1:8变速比），自闭式皮革止逆单向水阀，提水效率与扬程达传统翻车八倍。
- 双动活塞风箱：干透圆木掏空为缸，皮革/羽毛密封活塞，推拉皆连续出风，将土高炉温推升至1200度以上，完成生铁熔化脱碳。
- 模块化曲辕犁：弯曲辕身、可调深浅犁评与翻土排泥犁壁，独牛轻松牵引，耕作效率翻三倍。
- 粗盐提纯法：溶解过滤沉淀泥沙重金属、加醋沉淀、多级结晶，产出纯白无苦味之细雪精盐。

### 2. 第二阶梯：依托庄园熟练老兵工匠，1至3个月内可成
- 水力连环八联锻锤：终南山湍急溪流驱动硬木凸轮轴，连续击打百斤锻铁大锤，千层钢坯成型时间缩减九成。
- 马蹄铁与高桥马鞍：U型熟铁条定于马蹄角质壳，使战马磨损报废率降低七成，战备巡航寿命倍增。
- 矿渣火山灰水泥：高炉废铁渣粉磨细，混生石灰石膏黏土熟化，具备水下硬化特性，用于浇筑渠坝涵洞。

### 3. 第三阶梯：依托国家朝廷机器协同推进之战略级工程
- 机械造纸与活字铜模工坊（需全国采麻制浆与官方雕模）。
- 帝国平整硬化官道（大唐国道，需户部以工代赈征集万民）。
- 蒸汽动力与混合动力大型平底钢壳舰队（需大型官营造船坞与高强气密材料）。

## [记忆卡-12] 随身生活造物与军工神器落地考证

### 1. 蜂窝煤（唐代绝无，开局最暴利之暖民神器）
- 历史真实：唐代北方已挖石炭原煤，但直接燃烧硫磺烟毒浓烈极易窒息，仅权贵用得起昂贵银丝木炭。
- 制造工艺：露天弃置之无用煤屑碎末（80%）+ 黄土黏土（15%）+ 消石灰粉（5%，关键固硫吸收毒气反应）+ 铁木脚踏冲压模具。
- 商业价值：成本近乎为零，无烟耐烧通宵不熄，迅速垄断关中冬季取暖市场，既解民生又聚巨资。

### 2. 透明玻璃与千里望远镜（军工与商战降维双杀）
- 历史真实：唐代仅有含铅钡浑浊有色低温琉璃，透明水晶器物全仗西域贡品。
- 烧制工艺：石英河砂 + 纯碱（草木灰水提纯）+ 石灰石，借助双动活塞风箱推至1300度熔融，加入微量软锰矿（无名异）完成物理脱色。
- 水银玻璃镜：平板玻璃背涂水银锡箔合金，彻底颠覆昏黄铜镜，收割世家名门千金。
- 军用双镜筒望远镜（千里镜）：凸透镜物镜 + 凹透镜目镜，组合成抽拉铜筒，视界延伸十里，成李靖与太宗手中之降维战场雷达。

### 3. 水蒸气蒸馏香水与纯露精油（后宫与青楼收割机）
- 制造工艺：天锅分馏出75度以上高纯谷物脱味酒精；紫铜蛇形冷凝管水蒸气蒸馏终南山玫瑰桂花提取纯植物精油；酒精混溶陈化装入小巧透明琉璃喷管瓶。
- 商业价值：取代厚重油腻之燃香与香发油，轻巧一喷满室生香，引发长安名媛疯抢。

### 4. 植物无铅化妆品与冷制甘油香皂（健康日化革命）
- 历史真实：唐代女子使用含铅华铅粉与水银粉涂面导致重金属中毒面皮溃烂，洗面用动物腥味之生猪胰子。
- 纯植物冷制香皂：熟猪油菜油 + 草木灰苛化强碱水皂化，析出天然甘油，加入精油压模，泡沫细腻清爽去污。
- 无铅蜂蜡口红与面霜：纯蜂蜡 + 甜杏仁油 + 纯植物天然茜草红花提取红素，浇筑入黄铜旋转管，成大唐首创现代口红。
