# 核心写作与排版规范（永久记忆库）

## 1. 文本符号硬性铁律（最高优先级）
* **【绝对零星号】严禁在任何章节的正文中出现任何星号（`*`）**：
  * 禁止使用 Markdown 粗体语法（如 `**加粗**` 会在网文阅读器中显示成生硬星号）。
  * 禁止使用 Markdown 列表星号（如 `* 列表项`）。
  * 禁止任何充当分割线或装饰的 `***`。
  * **强调方式**：一律使用网文原生排版，例如方括号 `【系统提示】`、书名号 `《租客守则》`、顿号、双引号 `“...”` 或全角叹号 `！`。

## 2. 段落与阅读节奏规范
* **短段留白**：每段保持在 1~3 句话以内，移动端阅读严禁大段密实黑块。
* **情绪渲染**：弹幕反应、全网震惊、高层会议分析等侧面描写必须层次分明，与主角苏白的死宅冷面吐槽形成强烈反差。
* **钩子设置**：每章末尾必须留下强悬念钩子，诱导读者点击下一章。
