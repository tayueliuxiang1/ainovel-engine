# 技术成熟度与推广范围台账 (Technology Maturity State)

## 一、已全流程实证且投入商业与官造运转之技术
1. 双级斜齿排渣轴瓦提水神车（及水力四联框锯、三轴联动钻机、二十四道精钢通止卡规）
   - 成熟度：获正八品上少府监右尚署署令统筹关中八十架官造抗旱大单，借「云阳母坊卡规总验+各县十八贯分包木件+渭南十二家分包铁箍」标准化体系推进，第41章已验收首批200对五寸半熟铁大包箍与800件精密夹片，零裂纹全通卡规。
2. 植物油草木灰盐析二重皂化清洁膏（「云阳雪莲玉脂」及家用平价皂）
   - 成熟度：完成纯素山野漆树籽蜡配胡麻芸薹油迭代，由聚丰号统筹向长安佛堂内宅与各地常客稳健走货回血。
3. 十二孔石灰固硫蜂窝煤饼与「铁箍弯脖 + 耐火灰陶」保温暖泥炉（第36至41章突破迭代）
   - 民用安全铁律：强制配套顺墙/窗洞外排拔火烟囱（第39章牛皮帐+银针+公鸡实测半时辰，不接烟囱者云阳一律拒卖、照规失误十倍包赔）。
   - 配比与产能：8满斗淘洗沥干煤细粉 + 1.5斗细老黄土 + 0.5斗熟石灰膏，百余山民轮班石碾淘粉、十二台脚踩杠杆压饼机配两座烧煤苇席烘干暖房，单枚庄内死成本不足半文；外运交由聚丰30来辆轮休双骡重车双向回拉压运脚至不足3厘。
   - 炉具「改陶加冷铆」定型：由Ch39二尺薄铁皮烟囱改作Ch40-41「聚丰废油桶铁箍冷剪冷铆半尺弯脖风门 + 樊川瓦窑多孔耐火厚陶箅子及粗陶素坯内胆 + 一文一节三寸子母灰陶长烟筒」，单炉熟铁降至半斤出头，全炉连工带料本钱压进30文以内，已在长安九大坊巷日均畅销近万枚。
4. 青砖闷窑干馏高热「炼焦熟炭块」（第37至41章工业线定型）
   - 工艺特征：云阳背风荒坡四座（Ch38砌两座、Ch41扩至四座）青砖焖窑圆炉配斜坡引烟道，深层原煤块层间撒青白生石灰碎粒，闭九成风门700-800度高温焖蒸去硫及煤焦油并急水退火。
   - 物性与产销：轻三成、敲击如金石、遍体银灰多孔，30息窜起纯青白焰烧透白热、80余记重锤丝毫不脆且绝对不糊铁匠风口；庄内工本百斤25文，专供渭南十二家水车分包铁铺百斤30文微利；Ch41东市新总栈试烧放风引发长安兵器农器大铁坊抢购，开价百斤35至40文现铜钱，并已引动工部虞部司及将作监左校署关注查核。
