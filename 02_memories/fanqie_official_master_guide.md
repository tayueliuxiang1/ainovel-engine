# 番茄官方长篇爆款创作全景工程手册 (Fanqie Master Bible)

## 概述
本手册全面深度整合番茄小说官方作家专区全部二十二篇核心指南与作家课堂干货，彻底转化为全书《大唐第一工科生》（80万字长篇巨著）的底层操作系统、创作工程蓝图与终身品控铁律。
本手册分为五大核心工程模块，全书每一卷、每一章、每一句话的创作与修改，均严格执行本法典。

## 一、 宏观架构与长篇防崩防疲软工程（吸取官方百万长篇上下篇、防崩指南）

### 1. 百万长篇防翻车三阶骨架
- 阶段性目标驱动：拒绝无目标的松散流水账。全书划分为清晰的五卷，每一卷设立一个不可逾越的生死阶段目标（卷一引渭水救关中破门阀阴谋；卷二玄甲骑破突厥定漠南；卷三格物工业破世家经济垄断；卷四经略西域互市通欧亚；卷五蒸汽与钢铁定鼎全球万国来朝）。
- 告别中期疲软的升级法则：
  旧矛盾解决之时，必须顺理成章撕开更大维度的矛盾裂口。
  当蓝田县水车成功解决，绝不进入安乐窝，立刻引出工部与世家把持水利利益链条的围剿；打掉工部崔氏，立刻引出突厥借大旱南侵的国难之危。
  危机呈螺旋式上升，让读者始终处于紧张的期待感中。

### 2. 四线并行与交汇管控（一张表管好故事线）
- A线【主角工科升级主线】：小木样水车 -> 斜齿轴瓦真高车 -> 引水上高塬大水利 -> 炼焦炼铁水泥工业化 -> 大漠千里望远镜与火器 -> 远洋动力船舰。
- B线【世家门阀博弈线】：崔浩冒功抢祥瑞 -> 博陵崔氏宗族打压 -> 京兆五姓七望联手垄断 -> 经济与金融工业决战。
- C线【君臣相知与帝国博弈线】：李世民为大旱震怒焦头烂额 -> 惊见云阳庄神车 -> 微服私访君臣定计 -> 结为帝国机密合伙人 -> 扫平四海封天可汗。
- D线【关中家庭与袍泽情感线】：老爹苏成海的护短与武人傲骨、母亲陆氏的持家温情、二十四位天策府伤残老卒重焕军工尊严。
- 交汇规则：每3至5章必须安排一次AB线正面冲突碰撞，每卷末尾四线在最高潮全面汇聚爆发（如卷一太极殿御前实物对决大反杀）。

## 二、 伏笔管理与防填坑火葬场工程（吸取官方伏笔表教程）

### 1. 建立专职伏笔登记表 (foreshadowing_registry)
- 每一处伏笔必须录入档案：记录伏笔编号、埋设章节、伏笔类型、计划填坑章节、关联人物、回收方案与爽感闭环。
- 绝不无限套娃：小悬念在10至20章内给出阶段性反馈；大主线伏笔在整卷收束时彻底揭开。

### 2. 伏笔回收的黄金法则：闭环加拔高
- 严禁为了填坑而生硬填坑；
- 回收旧伏笔时，必须同时带出打脸、升级或核心利益到手的剧烈爽感，让读者惊呼细节铺垫之深。

## 三、 单章3:6:1黄金结构模型与节奏调控（吸取官方节奏篇、单章篇、爆款篇）

### 1. 单章黄金结构配比
- 黄金前300字：无废话入局。坚决斩断前情提要、天气描写与自白，开篇第一秒直接抛出核心危机、动作交锋或高压对白。
- 3分铺垫蓄力（约600字）：现实绝境压迫、反派咄咄逼人，把主角团逼入死角，憋屈感拉满。
- 6分推进与交锋（约1200字）：硬核工科降维反击、行动白刃战、矛盾白热化爆发，局势飞速向前推进。
- 1分强悬念急刹车（约200字）：在冲突引信被点燃、胜负即将揭晓或危机反扑的最高压强瞬间悍然断章，诱导读者疯狂追读。

### 2. 单章单一使命原则
- 每一章2000字必须有且仅有一个明确的剧情攻坚目标（如：画出神机图纸、挡住门外抓人捕快、当堂揭穿假祥瑞），绝不东一榔头西一棒子。

## 四、 活体人物群像与拒绝千人一面（吸取官方人物篇、工具人篇、纸片人篇）

### 1. 反派活体化法则
- 拒绝无脑作恶与降智小丑：反派有脑子、有阶级本能与利益算盘。崔浩行恶是源于门阀血统优越感与族内夺权焦虑，他的每一招都踩在大唐律法和朝廷抗旱痛点上。
- 反派有软肋与恐惧：崔浩最怕欺君死罪，崔氏最怕皇权借工匠敲打门阀。

### 2. 配角性格在压力测试中立定
- 拒绝纸片工具人，人物性格必须在生死抉择中爆发：
  老爹苏成海：平时大口嚼葱骂娘，县衙抓人时横刀立马替老兄弟顶雷；
  老铁匠陈铁锤：平日自认残废，见到绝世机关图噗通下跪愿效死命；
  母亲陆氏：温婉持家，门阀恶仆上门时挺身护子分毫不让。

## 五、 文字做减法与发稿前四步自查（吸取官方减法篇、自查篇、防划走篇）

### 1. 文字减法与竖屏心流
- 彻底斩断长难句：能用短句不用长句，能用句号不用逗号，1至3句成段。
- 坚决删除冗余副词与过渡词（去掉极其、非常、毫无疑问、不由自主等水词），用强动词替代。
- 坚决杜绝文青散文病与舌尖报菜名：不写空洞风景，不罗列食材器皿，动作即信息。
- 对白自带微动作：严禁角色干站着背台词，对话必配神态与手头动作，拒绝说明书。

### 2. 发稿前必做四步自查规程
- 第一步【硬伤排查】：错别字、标点规范、敏感词违规规避、绝对零星号字符核验；
- 第二步【逻辑自洽】：时间线、官职称谓（如贞观元年严禁称天可汗）、力学数据与因果逻辑严丝合缝；
- 第三步【人设与对白】：检查角色语气是否符合身份，有无降智或念说明书现象；
- 第四步【断章钩子核验】：检查章末是否具备让人欲罢不能的强钩子，排查平淡结尾。
